# A quota place is separate from an Entry's qualification status

"Belgium has a place" and "this Athlete or Team is going" are different facts, so we model them as two things. A **Quota place** belongs to Belgium in one event at one Games and has its own lifecycle (Provisional → Allocated → Accepted → Entered, or Declined / Lost). A **Qualification status** belongs to an Entry for one target (next Games or next Championship). We considered a single per-athlete status ladder, but it cannot represent places that the NOC owns rather than the athlete (most team, boat and winter sports), sports that mix NOC-owned and named places, nation rankings that earn a *number* of places athletes only contribute to, or places that pass from one partnership to another. The cost is an extra state, **Eligible**, so that three Belgians chasing two NOC places don't all show as Qualified. Both are curated values with a source and last-checked date, because only 3 of 36 LA28 sports have a live tracker. See [One qualification status model for every sport](https://github.com/AnoukCeyssens/BelgianSportsHub/issues/10).
